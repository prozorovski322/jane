# Jane

Мобильное приложение для изучения английского с нуля (Pre-A1) до продвинутого уровня (C1) для
русскоязычных. Сейчас готовы уровни Pre-A1, A1 и A2; B1–C1 есть в плане курса и появятся обновлениями. iOS и Android, полностью офлайн, без подписок и рекламы.

Expo SDK 57 · React Native 0.86 · TypeScript (strict) · Expo Router · Zustand · expo-sqlite · Zod.

## Команды

```bash
npm install
npm run content:check   # проверка всего контента (схемы, ссылки, уровень лексики, транскрипции)
npm run content:build   # проверка + сборка бандла в src/core/content/generated
npm run typecheck
npm run lint
npm test
npm run web             # веб-сборка для быстрой проверки экранов
npm start               # dev-сервер для Expo Go / dev client
```

После любой правки в `content/` нужно запустить `npm run content:build` и закоммитить
сгенерированные файлы — CI проверяет, что они совпадают с исходниками.

## Структура

```
app/                    экраны (Expo Router)
src/core/content/       схема контента (Zod), парсер грамматики, лемматизатор, загрузка бандла
src/core/checker/       локальная проверка письма и устных ответов
src/core/scoring/       нормализация ответов, плитки
src/features/           функции приложения (урок, повторение, тест уровня, профиль…)
content/                исходники курса: юниты (JSON), грамматика (Markdown), служебная лексика
scripts/                сборка и проверка контента
```

## Контент

Юнит — файл `content/levels/<level>/uNN-*.json`. В нём слова (с IPA, переводами и примерами),
тексты (чтение и диалоги), уроки с заданиями и итоговый тест. Схема описана в
`src/core/content/schema.ts`. Грамматические заметки — `content/grammar/<level>/*.md`; синтаксис
описан в `src/core/content/grammar-md.ts`.

Что проверяет `content:check`:

- соответствие схемам, уникальность и формат идентификаторов, ссылки на слова, тексты, грамматику;
- целостность каждого задания: индекс ответа, число пропусков, плитки вариантов, ошибочный
  фрагмент, образцы ответов проходят собственные критерии проверки;
- язык строк: в английских нет кириллицы, в русских нет латинских «двойников» букв;
- уровень лексики: каждое английское слово в текстах и заданиях уже введено в этом или
  предыдущих юнитах (с учётом форм слова, сокращений и неправильных глаголов);
- транскрипции: формат IPA и сверка согласных и ударения с CMUdict;
- полнота юнита: есть чтение, аудирование, говорение, письмо и произношение; у каждого слова есть
  задание, у каждого текста — урок.

Произношение — американское. Транскрипции без косых черт, с ˈ ˌ и ː.

## Конфиденциальность

Все данные хранятся только на устройстве. Трекеров нет. Подробности — в `PRIVACY.md`
(появится на этапе 8).
