## Как проверяется работа

- Логика — Jest и React Native Testing Library.
- Экраны — веб-сборка во встроенном браузере (приближение, не устройство).
- Реальное устройство — Expo Go / dev client на телефоне владельца проекта.
- e2e — Maestro в CI на Android-эмуляторе. iOS-сборки — EAS (облако).

На этой машине нет Android SDK и macOS: всё, что проверено только в вебе, так и отмечается
в отчётах.

## Программа A1 (черновик)

Около 10 юнитов по 6–7 уроков, около 800 слов. Каждый юнит: слова, грамматика, произношение,
аудирование, чтение, письмо и говорение, итоговый тест. В конце уровня — большой тест с разбором.

| Юнит | Тема            | Грамматика                                                  |
| ---- | --------------- | ----------------------------------------------------------- |
| 1    | Знакомство      | to be (утверждение), a/an с профессиями, алфавит            |
| 2    | Семья и друзья  | to be: вопросы и отрицания, притяжательные, 's, числа 0–100 |
| 3    | Мои вещи        | this/that/these/those, множественное число, a/an/the        |
| 4    | Дом             | there is/are, предлоги места                                |
| 5    | Мой день        | present simple, время, предлоги времени                     |
| 6    | Еда             | исчисляемые и неисчисляемые (база), some/any, like + -ing   |
| 7    | Город           | can, повелительное наклонение, направления                  |
| 8    | Покупки         | how much/many, цены, числа до 1000, I'd like                |
| 9    | Прямо сейчас    | present continuous и present simple, погода, одежда         |
| 10   | Свободное время | вопросы с do/does, wh-вопросы, наречия частоты              |

## Целевые серии по трудностям русскоговорящих

Артикли, порядок слов, времена, предлоги, ложные друзья, произношение (th, w/v, r, долгота
гласных). Задания помечаются тегом трудности (`troubles`), серии собираются в `content/targeted/`
и в разделе «Слабые места».
