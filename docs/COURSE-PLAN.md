### Оценка и открытие уровней

- **Мини-тест юнита** (есть): порог по юниту.

- **Треки**: открываются после сертификата B1.

### Тематические треки (необязательные, после B1)

- **Деловой английский** (~6 юнитов): письма, встречи, презентации, переговоры.
- **Путешествия** (~4 юнита): аэропорт, отель, транспорт, ситуации в поездке.
- **IELTS / TOEFL** (~8 юнитов): форматы заданий по всем частям, стратегии, пробные тесты. Это подготовка, а не гарантия балла.

## 3. Схема данных

Контент хранится отдельно от кода, как и сейчас: источники в `content/` (JSON и Markdown), сборка и проверка скриптами, готовый пакет в `src/core/content/generated`.

### Контент (файлы)

```
course.json                   — версия, уровни, порядок
levels/<lvl>/level.json       — цели CEFR («после уровня умею…»), объём лексики, функции языка
levels/<lvl>/exam.json        — экзамен уровня
levels/<lvl>/m<N>-<slug>/
  module.json                 — id, название, цели, порядок юнитов
  test.json                   — контрольная модуля
  u<NN>-<slug>.json           — юнит: слова, тексты, уроки, мини-тест (как сейчас)
tracks/<slug>/…               — то же, но с полем requires: "B1"
grammar/<lvl>/*.md            — грамматические заметки (как сейчас)
```

### Новые и изменённые типы (Zod)

```ts
Level      = 'PA1' | 'A1' | 'A2' | 'B1' | 'B2' | 'C1'      // + порядок и накопительные пороги лексики
LevelInfo  = { level, title, canDo: Ru[], grammarScope: Id[], vocabTarget: number, functions: Ru[],
               modules: Id[], exam: Exam }
Module     = { id, level, order, title: Bilingual, goals: Ru[], units: Id[], test: ModuleTest }
Unit       = { …как сейчас…, moduleId }                    // id юнитов не меняются
Exam       = { passScore, exercises: Exercise[] (по навыкам, quota на навык) }
Track      = { id, title, requires: Level, units: Id[], finalTest }
```

Id уроков и юнитов остаются прежними (`a1.u01.l01`), поэтому прогресс, карточки и история не теряются.

### Прогресс пользователя (SQLite)

- `lesson_results.kind` расширяется до `module_test` и `level_exam` (в SQLite для этого пересоздаётся таблица, миграция v5).
- `certificates (level, earned_at, score, source)`: `source` = `exam` или `placement`; наличие записи открывает следующий уровень.
- Остальное без изменений: `lesson_progress`, `attempts`, `srs_cards`, `daily_activity`, достижения.
- Раздел «Ошибки» и «Смешанное повторение» строятся запросами к `attempts`, новых таблиц не нужно.
- Оценка срока до уровня: уроки до экзамена ÷ средний темп за 14 дней, показывается как «примерно N недель», при малой истории — без цифры.

## 4. Упражнения

Уже есть все нужные виды: выбор, пропуски, сопоставление, порядок слов, аудирование, запись голоса, свободное письмо (+ исправление ошибки, диктант, пары звуков, ударение). Для Pre-A1 понадобится:

### Как это устроено (шаг 1)

- `content/course.json` описывает уровни и модули. В модуле `units` — написанные юниты, `planned` — запланированные (в приложении «Скоро»). Когда юнит написан, его переносят из `planned` в `units`; проверка контента не пропустит юнит в обоих списках сразу или с ошибочной нумерацией.
- **Контрольные модулей и экзамены уровней не пишутся отдельно, а собираются из заданий юнитов** (по долям навыков, новый набор при каждой попытке): модуль 20 заданий, порог 70%; уровень 50 заданий, порог 75%. Они становятся доступны, когда написаны все юниты модуля или уровня. Идентификаторы: `a1.m1.test`, `a1.exam`; результаты хранятся как обычные тесты (`kind = test`), миграция таблицы результатов не понадобилась.
- Сертификат: таблица `certificates` (миграция v5). Экзамен даёт сертификат с баллом; тест уровня засчитывает нижние уровни (`source = placement`) и не перезаписывает экзамен.
- Раздел «Ошибки» берёт из `attempts` последние неверные ответы за 30 дней; тренировка «Ошибки» и «Смешанная грамматика» добавлены в «Практику».
- Входной тест знает Pre-A1 (10 заданий) и C1 (10 заданий); «Начинаю с нуля» теперь ведёт в Pre-A1.
- Треки описаны в схеме (`tracks` в `course.json`, пока пустые).

- В `course.json` три трека: «Путешествия» и «Деловой английский» (с B1, по 6 юнитов) и «Подготовка к IELTS и TOEFL» (с B2, 8 юнитов). - Проверка словаря для трека начинается со словаря уровня, который трек требует (а не всего курса). Если трек учит слово, которое в курсе появляется позже, он использует тот же id — в словаре и в повторении остаётся одна запись.
