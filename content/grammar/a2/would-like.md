## Вежливое «хочу»

**Would like** звучит мягче, чем want. Форма одна для всех лиц.

| Кто  | Сокращение  | Пример                      |
| ---- | ----------- | --------------------------- |
| I    | I'd like    | I'd like a coffee, please.  |
| she  | she'd like  | She'd like to see the film. |
| they | they'd like | They'd like some tea.       |

> I would like to see a film. | Я хотел бы посмотреть фильм.
> She would like a cup of tea. | Она хотела бы чашку чая.

## Предложения и приглашения

> Would you like a coffee? | Хотите кофе?
> Would you like to come to the cinema? | Хотите пойти в кино?

Ответы:

| Согласие          | Отказ           |
| ----------------- | --------------- |
| Yes, I'd love to. | Sorry, I can't. |
| Yes, please.      | No, thank you.  |

TIP: После would like нужен to перед глаголом: would like to come. Перед существительным to не нужен: would like a coffee.

## Типичные ошибки

! Would you like come? => Would you like to come? | Перед глаголом нужно to.
! Do you would like tea? => Would you like tea? | Would сам образует вопрос.
! I like to see you tomorrow. => I would like to see you tomorrow. | Для вежливой просьбы нужен would.
