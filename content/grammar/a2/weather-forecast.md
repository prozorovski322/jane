## It will be…

Погоду описывают конструкцией **it will be** и прилагательным.

| Прилагательное | Значит     |
| -------------- | ---------- |
| rainy          | дождливый  |
| snowy          | снежный    |
| foggy          | туманный   |
| stormy         | штормовой  |
| cool           | прохладный |

> It will be rainy tomorrow. | Завтра будет дождливо.
> It is going to be windy. | Будет ветрено.
> What will the weather be like? | Какая будет погода?

## Температура и осадки

> The temperature will be ten degrees. | Температура будет десять градусов.
> There will be heavy rain. | Будет сильный дождь.
> There will be a strong wind. | Будет сильный ветер.

TIP: Для существительных rain, snow, wind говорят there will be, для прилагательных — it will be: there will be rain, it will be rainy.

## Типичные ошибки

! It will be rain tomorrow. => It will be rainy tomorrow. | После be нужно прилагательное rainy.
! The weather will be ten degrees. => The temperature will be ten degrees. | О градусах говорят temperature.
! It will snowy. => It will be snowy. | Пропущен be.
