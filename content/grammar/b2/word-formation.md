## Существительные

| Суффикс | Пример                       |
| ------- | ---------------------------- |
| -tion   | inform → information         |
| -ment   | govern → government          |
| -ness   | aware → awareness            |
| -ity    | popular → popularity         |
| -er/-or | read → reader, edit → editor |

## Прилагательные

| Суффикс | Пример                            |
| ------- | --------------------------------- |
| -ful    | harm → harmful (вредный)          |
| -less   | harm → harmless (безвредный)      |
| -ive    | addict → addictive (затягивающий) |
| -able   | rely → reliable (надёжный)        |

## Отрицание

> dishonest, impossible, inaccurate, unreliable, misleading | нечестный, невозможный, неточный, ненадёжный, вводящий в заблуждение

- dis- — dishonest, disagree, dislike.
- im- перед p и m — impossible, impolite.
- in- — inaccurate, informal.
- mis- — «неправильно»: misunderstand, mislead.

TIP: Information и advice — неисчисляемые: much information, a piece of advice. Informations и advices не бывает.

## Типичные ошибки

! He is unhonest. => He is dishonest. | Нужна приставка dis-.
! It's unpossible. => It's impossible. | Перед p — im-.
! There are many informations online. => There is a lot of information online. | Information — неисчисляемое.
