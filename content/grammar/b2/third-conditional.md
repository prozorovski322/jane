## Если бы тогда…

> If I had known about the party, I would have come. | Если бы я знал о вечеринке, я бы пришёл.
> If she hadn't missed the train, she wouldn't have met him. | Если бы она не опоздала на поезд, она бы с ним не познакомилась.
> We would have won if Tom had played. | Мы бы выиграли, если бы Том играл.
> If you had asked me, I could have helped. | Если бы ты попросил, я бы смог помочь.

## Схема

| Часть с if          | Главная часть                    |
| ------------------- | -------------------------------- |
| If + had + V3       | would have + V3                  |
| If I had left early | I would have caught the train.   |
| If it hadn't rained | we might have gone to the beach. |

- Would have — точно бы сделал.
- Could have — смог бы.
- Might have — может быть, сделал бы.

TIP: В речи had и would оба сокращаются до 'd: If I'd known, I'd have come. Первое 'd — had, второе — would. В части с if would не бывает.

## Типичные ошибки

! If I would have known, I would have come. => If I had known, I would have come. | В части с if — had, не would have.
! If I had known, I would come. => If I had known, I would have come. | О прошлом — would have + V3.
! If she hadn't missed the train, she wouldn't have meet him. => If she hadn't missed the train, she wouldn't have met him. | После have — третья форма.
