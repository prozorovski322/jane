## Цель: зачем?

| Форма               | Пример                                         |
| ------------------- | ---------------------------------------------- |
| to + V              | I recycle bottles to reduce waste.             |
| in order to + V     | We cycle to work in order to save money.       |
| so that + can/could | I turned off the light so that he could sleep. |

> I recycle bottles to reduce waste. | Я сдаю бутылки на переработку, чтобы сократить отходы.
> I turned off the light so that he could sleep. | Я выключил свет, чтобы он мог поспать.

## Результат: так…, что

| Форма                          | Пример                                         |
| ------------------------------ | ---------------------------------------------- |
| so + прилагательное + that     | The air was so dirty that we couldn't breathe. |
| such a + прилагательное + сущ. | It was such a good idea that everybody agreed. |

> The air was so dirty that we couldn't breathe. | Воздух был такой грязный, что нельзя было дышать.
> It was such a good idea that everybody agreed. | Идея была такая хорошая, что все согласились.

TIP: Русское «чтобы» почти всегда to: «пришёл, чтобы помочь» — came to help. For + глагол — ошибка.

## Типичные ошибки

! I came here for learn English. => I came here to learn English. | Цель — to + глагол.
! It was so a good idea. => It was such a good idea. | Перед a + существительное — such.
! It was such cold that we stayed home. => It was so cold that we stayed home. | Перед одним прилагательным — so.
