## Что где находится

По-русски мы говорим «в комнате есть диван». По-английски нужна конструкция **there is** (для одного предмета) и **there are** (для нескольких). Слово there здесь не переводится как «там».

> There is a sofa in the living room. | В гостиной есть диван.
> There are two chairs near the table. | Возле стола два стула.

TIP: Предложение начинается с there is / there are, а место обычно называют в конце. Так же говорят о себе: In my room there is a bed.

## Вопросы и отрицание

| Утверждение            | Вопрос                 |
| ---------------------- | ---------------------- |
| There is a lamp.       | Is there a lamp?       |
| There are two windows. | Are there two windows? |

> Is there a bathroom? — Yes, there is. | Есть ли ванная? — Да.
> Are there two bedrooms? — No, there aren't. | Есть две спальни? — Нет.

Для отрицания добавляют not: There is not a plant. There isn't a plant. There aren't two chairs.

## Сколько? How many…?

Количество спрашивают так: **How many** + предмет во множественном числе + are there?

> How many rooms are there? | Сколько там комнат?
> There are four rooms. | Там четыре комнаты.

## Типичные ошибки

! There are a sofa. => There is a sofa. | Один предмет — there is.
! There is two chairs. => There are two chairs. | Несколько предметов — there are.
! Is a sofa in the room? => Is there a sofa in the room? | Вопрос с there is начинается с is there.
