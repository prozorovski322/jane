## Три формы

| С if                           | Без if                             |
| ------------------------------ | ---------------------------------- |
| If I had known his story, …    | Had I known his story, …           |
| If you need any help, call me. | Should you need any help, call me. |
| If I were to do it again, …    | Were I to do it again, …           |
| If it hadn't been for him, …   | Had it not been for him, …         |
| If it weren't for her, …       | Were it not for her, …             |

> Had I not known his story, I might have given up. | Если бы я не знал его историю, я бы, возможно, сдался.
> Should you have any questions, please contact us. | Если у вас возникнут вопросы, пожалуйста, свяжитесь с нами.
> Had it not been for Shackleton, none of them would have survived. | Если бы не Шеклтон, никто из них не выжил бы.
> Were it not for the sea, I would be bored. | Если бы не море, мне было бы скучно.

TIP: Отрицание при такой инверсии не сокращают: Had I not known, а не Hadn't I known.

## Типичные ошибки

! If had I known, I would have come. => Had I known, I would have come. | If убирают совсем.
! Hadn't I known his story, I would have given up. => Had I not known his story, I would have given up. | Not — полностью, после подлежащего.
! Should you will need help, call me. => Should you need help, call me. | После should — глагол без will.
