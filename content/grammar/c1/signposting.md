## Части лекции

| Задача                 | Фраза                                     |
| ---------------------- | ----------------------------------------- |
| объявить тему          | Today I'd like to look at…                |
| начать                 | Let me start by + -ing…                   |
| перейти дальше         | Moving on to… / Let's now turn to…        |
| пояснить иначе         | To put it another way… / In other words…  |
| сослаться на сказанное | As I mentioned earlier…                   |
| подвести к главному    | This brings me to my main point.          |
| привести пример        | Take, for example,…                       |
| подытожить             | To sum up… / So, what does all this mean? |

> Let me start by asking you a question. | Начну с вопроса к вам.
> Moving on to the research, what did they find? | Переходим к исследованию: что же обнаружили?
> To put it another way, we are not really doing two things at once. | Иначе говоря, на самом деле мы не делаем два дела одновременно.

TIP: После Let me start by, after, before — форма на -ing: Let me start by asking… Это частая ошибка: Let me start by ask.

## Типичные ошибки

! Let me start by ask you a question. => Let me start by asking you a question. | После by — -ing.
! Moving to the next point. => Moving on to the next point. | Moving on to.
! As I mentioned before it, … => As I mentioned earlier, … | Без it.
