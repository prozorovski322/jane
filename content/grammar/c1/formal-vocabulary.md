## Разговорно и официально

| Разговорно    | Официально              |
| ------------- | ----------------------- |
| get           | receive, obtain         |
| need          | require                 |
| help          | assist                  |
| buy           | purchase                |
| start         | commence                |
| ask about     | enquire about           |
| put off       | postpone                |
| sort out, fix | resolve                 |
| about         | regarding               |
| so            | consequently, therefore |

> I have not yet received a response. | Я пока не получил ответа.
> Further information is available on request. | Дополнительную информацию можно получить по запросу.
> Could you assist me with my application? | Не могли бы вы помочь мне с заявлением?

## Существительные вместо глаголов

| С глаголом                      | С существительным                          |
| ------------------------------- | ------------------------------------------ |
| We decided to close the office. | The decision was made to close the office. |
| Because it rained, the event…   | Due to the rain, the event…                |
| If you pay late, you will…      | Late payment will result in…               |

TIP: Не переусердствуйте: письмо из одних длинных слов звучит тяжело. Достаточно убрать сокращения и самые разговорные фразовые глаголы.

## Типичные ошибки

! I would like to enquire the course. => I would like to enquire about the course. | Enquire about.
! Could you assist me to write the application? => Could you assist me with the application? | Assist with + существительное.
! The meeting was postponed to tomorrow because of we had no room. => The meeting was postponed until tomorrow because we had no room. | Because of + существительное, because + предложение.
