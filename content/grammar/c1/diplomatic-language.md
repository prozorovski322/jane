## Прямо и дипломатично

| Прямо                   | Дипломатично                                  |
| ----------------------- | --------------------------------------------- |
| There's a problem.      | There seems to be a slight problem.           |
| Your price is too high. | Your price is a bit higher than we expected.  |
| You should wait.        | Wouldn't it be better to wait?                |
| We aren't ready.        | I'm not sure we're quite ready.               |
| That's wrong.           | I'm not sure that's quite right.              |
| Change the design.      | It might be a good idea to change the design. |

> There seems to be a slight problem with the delivery date. | Кажется, есть небольшая сложность со сроком поставки.
> Wouldn't it be better to start with a smaller order? | Может, лучше начать с заказа поменьше?
> The price is slightly higher than we had hoped. | Цена несколько выше, чем мы надеялись.

TIP: Англичане любят преуменьшение: a slight problem может означать серьёзную проблему. Слышите slightly, a bit, not quite — относитесь к этому внимательно.

## Типичные ошибки

! There seems a slight problem. => There seems to be a slight problem. | Seem + to be.
! Wouldn't it be better wait? => Wouldn't it be better to wait? | Better + to.
! It's a bit expensive too much. => It's a bit too expensive. | A bit + too + прилагательное.
