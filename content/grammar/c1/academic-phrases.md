## Утверждение и доказательство

| Задача             | Фраза                            |
| ------------------ | -------------------------------- |
| общепринятое       | It is widely accepted that…      |
| растущие данные    | There is growing evidence that…  |
| источник           | According to a recent report, …  |
| вывод из данных    | This suggests / indicates that…  |
| своя позиция       | This essay argues that…          |
| сравнение          | Similarly, … / Likewise, …       |
| противопоставление | In contrast, … / By contrast, …  |
| следствие          | Thus, … / Hence … / Therefore, … |

> There is growing evidence that green spaces improve mental health. | Становится всё больше данных о том, что зелёные зоны улучшают психическое здоровье.
> This suggests that trees are more than decoration. | Это говорит о том, что деревья — не просто украшение.
> In contrast, poorer areas often have very few trees. | В бедных районах, напротив, деревьев часто очень мало.

TIP: В эссе на C1 избегайте I think и I feel. Вместо них — This essay argues that…, It seems clear that…, The evidence suggests that…

## Типичные ошибки

! It is widely accepted, that trees help. => It is widely accepted that trees help. | Перед that запятая не нужна.
! According to the report, it says that… => According to the report, … | According to уже значит «по словам», it says лишнее.
! In contrary, poorer areas have fewer trees. => In contrast, poorer areas have fewer trees. | In contrast, а не in contrary.
